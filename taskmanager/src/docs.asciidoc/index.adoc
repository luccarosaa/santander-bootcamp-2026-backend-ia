== Códigos de status

|===
|Código |Descrição

|`200 OK`
|Requisição concluída com sucesso.

|`201 Created`
|Tarefa criada com sucesso.

|`400 Bad Request`
|Dados enviados são inválidos.

|`404 Not Found`
|Tarefa não encontrada.
|===
